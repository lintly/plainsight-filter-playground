# *Plainsight Filter Development Playground*
This is my playground for all open source development against the Plainsight Vision AI filters.

This project is a test for using Plainsight with my 2 RTSP cameras.
I will be setting up 1 to 2 cameras per pipeline.
Possibly do 1 camera to 1 pipeline.

We will utilze Docker and containers so we can bring up these containers fast.
All the filters I want to utilze from Plainsight will be opensource. We will be utilizing the `https://github.com/plainsightai` (GitHub) for all filters..
